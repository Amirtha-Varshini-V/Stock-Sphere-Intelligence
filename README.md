📊 Stock Sphere Intelligence

Inventory Analytics Dashboard using SQL + Microsoft Excel

📌 Project Overview

Stock Sphere Intelligence is an interactive inventory analytics dashboard built with SQL and Microsoft Excel. It transforms raw inventory transaction data into meaningful business insights for inventory monitoring, stock valuation, and decision-making.

This project is designed to showcase skills relevant to MIS Executive, Reporting Analyst, Inventory Analyst, and Junior Business Analyst roles.

🎯 Key Features

- Real-time Inventory Overview Dashboard.
- Total Stock In, Stock Out, Current Stock, and Stock Value KPIs.
- Top 10 Products by Stock Value.
- Monthly Stock In vs Stock Out Trend Analysis.
- Category-wise Inventory Value Distribution.
- Reorder Item Monitoring.
- Interactive Slicers for Year, Month, Product, and Category.

🛠️ Tools & Skills

- Microsoft Excel
- SQL
- Power Query
- Power Pivot
- DAX
- Pivot Tables
- Pivot Charts
- Slicers

📈 Dashboard Insights

- Monitor inventory movement across months.
- Identify high-value products and categories.
- Track available stock and reorder requirements.
- Analyze transaction activity through interactive filters.

💼 Business Use Case

This dashboard helps inventory and operations teams monitor stock levels, optimize inventory planning, and generate business reports for logistics, retail, and supply chain operations.
